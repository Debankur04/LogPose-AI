# LogPose AI

A modern AI productivity experience for planning tasks, summarizing ideas, and exploring workflows with a polished Next.js frontend.

- **Live demo site:** https://log-pose-ai.vercel.app
- **Frontend repository:** https://github.com/Debankur04/LogPose-AI

## What LogPose AI Does

LogPose AI brings an intelligent planning assistant to the browser. It transforms natural language prompts into structured workflows, recommendations, and useful planning output.

Built with Next.js, Tailwind CSS, and AI-driven chat experience patterns, this frontend delivers a fast, responsive interface for modern product planning.

## Key Features

- **Smart planning interface:** Capture goals and get instant planning guidance.
- **Chat-driven workflow:** Interact with AI-assisted planning prompts and explore recommended next steps.
- **Production-grade UI:** Uses Next.js 16 and React 19 for a polished, responsive experience.
- **API-powered architecture:** Connects to a backend AI service at the live API endpoint.
- **Deploy-ready:** Designed to run smoothly on Vercel or any Next.js-compatible hosting.

## Why It Matters

LogPose AI helps users move faster from idea to execution by combining conversational planning with clean task-focused UI. It is ideal for product teams, founders, and developers who want a simple way to prototype planning workflows.

## Getting Started

### Install dependencies

```powershell
npm install
```

### Run locally

```powershell
npm run dev
```

Open http://localhost:3000 to view the app.

### Build for production

```powershell
npm run build
npm run start
```
